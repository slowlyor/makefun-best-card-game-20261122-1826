Ember Court is a turn-based card duel against the Ashen Warden: each side has 30 life, draws a card and gains ember every turn, and plays creatures and spells from four original suits — Flame, Tide, Thorn and Gale, each told apart by colour and glyph. Spend ember wisely, trade creatures or go for the hero, and take the court before the ashes take you. It runs entirely from static files with mouse and keyboard controls (click a card, then a target; keys 1–7 play cards, Space ends the turn) and synthesized WebAudio sounds.

## Run it

```sh
python3 -m http.server 8080 --directory game
```
